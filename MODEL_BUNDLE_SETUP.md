# Intent ONNX Bundle Setup

Repo does not track model binaries because GitHub rejects files larger than 100 MB.

## What collaborators need

Get the runtime bundle zip generated by:

```powershell
python -X utf8 training/export_onnx.py
```

Bundle path:

```text
dist/intent_onnx_runtime.zip
```

## Install

Extract the zip so the final structure becomes:

```text
models/
  intent_onnx/
    model.int8.onnx
    label_config.json
    config.json
    tokenizer.json
    tokenizer_config.json
    special_tokens_map.json
    sentencepiece.bpe.model
```

## Run

Start the API normally:

```powershell
python -m uvicorn app.main:app --reload --port 8000
```

If the bundle is installed correctly, the API will use local ONNX intent classification automatically.
